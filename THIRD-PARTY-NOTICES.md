# Third-Party Notices

## TheDraw TDF font packs

`assets/fonts/*.tdf.gz` contains 36 TheDraw font packs retrieved through TAAG's [TheDraw font sets](https://patorjk.com/software/taag/tdf-font-sets/) page. The catalog in `assets/fonts/catalog.json` indexes the named records in those packs.

Roy/SAC's [TheDraw font collection](https://www.roysac.com/thedrawfonts-tdf.html) describes its collection as “All Free!” The packs contain fonts from many contributors, and the TDF records do not provide reliable per-font author or license metadata. The collection-level description does not identify the terms for each record. Roy/SAC's site also says that some material belongs to other authors, so its license statement for his own work cannot be applied to every bundled font.

The font data remains separate from sysclet's GPL-3.0-only code. This repository does not assign a common license to the bundled fonts. Consult the source collection or the relevant rights holder for terms that apply to a specific font.

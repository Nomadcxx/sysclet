# Third-Party Notices

## TheDraw TDF font packs

`assets/fonts/*.tdf.gz` contains TheDraw font packs. The 36 packs named `tdf-chunk-*`, `tdf-bleach` and `tdf-fategate` were retrieved through TAAG's [TheDraw font sets](https://patorjk.com/software/taag/tdf-font-sets/) page. The `tdf-phosphor-*` packs hold 723 further records from [Phosphor](https://github.com/0xc1c4da/phosphor)'s copy of the same collection, commit `2cfb1cc`, imported by `scripts/import_fonts.py`. The catalog in `assets/fonts/catalog.json` indexes the named records in those packs.

Roy/SAC's [TheDraw font collection](https://www.roysac.com/thedrawfonts-tdf.html) describes its collection as “All Free!” The packs contain fonts from many contributors, and the TDF records do not provide reliable per-font author or license metadata. The collection-level description does not identify the terms for each record. Roy/SAC's site also says that some material belongs to other authors, so its license statement for his own work cannot be applied to every bundled font.

The font data remains separate from sysclet's GPL-3.0-only code. This repository does not assign a common license to the bundled fonts. Consult the source collection or the relevant rights holder for terms that apply to a specific font.

## sysc-Go BIT fonts

`assets/fonts/tdf-bit-*.tdf.gz` contains 155 fonts converted from [sysc-Go](https://github.com/Nomadcxx/sysc-Go)'s `.bit` files into TheDraw block records by `scripts/import_fonts.py`. The conversion keeps each glyph's characters and maps FIGlet hardblanks (`$`) to spaces. Each font keeps the author and license its `.bit` file declares, listed below. A name in parentheses is the original `.bit` name where sysclet shortened it to fit a TDF record.
